# Каталог букмекеров

Виджет получает `bookmakers.json` с того же сайта: полный список России
и подборку со страницы «Лучшие букмекерские конторы», выбранной пользователем. Порядок соответствует карточкам источника,
не является собственной оценкой «Трибуны». В подборке лучших минимальный депозит
и маржа передаются только при наличии этих значений у источника.

Дата внизу виджета — время получения снимка. Весь выбранный список загружается
сразу; он доступен прокруткой, клавиатурой, кнопками вверх/вниз и через поиск.
Переключатели не переводят пользователя на стороннюю страницу.

Сейчас GitHub Pages публикует проверенный снимок из `docs/`; автоматическое
обновление рейтинга ещё не включено. Дата в виджете показывает возраст снимка.
В `deploy/pages.workflow.yml` подготовлен workflow для обновления каждые шесть
часов. Чтобы активировать его, нужно перенести файл в `.github/workflows/pages.yml`
и выбрать GitHub Actions источником публикации в Settings → Pages. Учётной записи,
которая добавляет workflow, требуется соответствующее право GitHub.
При ошибке планового обновления workflow сохраняет предыдущую публикацию.

Ручное обновление обоих снимков (`frontend/` и `docs/`) из корня репозитория:

```sh
node scripts/sync-bookmakers.mjs
node scripts/test-sync-bookmakers.mjs
```

Для сервера с Go необходим Node.js 22+ только на машине, где запускается
обновление. Сам Go-сервер отдаёт готовый `frontend/bookmakers.json` без Node.js.
Обновления на собственном сервере выполняются этой же командой по его расписанию.

Проверка виджета в браузере при запущенном сервере `docs/` (требуется Playwright):

```sh
WIDGET_TEST_URL=http://127.0.0.1:8977 node scripts/test-bookmakers-widget.mjs
```
