# Трибуна.ру

Спортивный новостной портал с собственной журнальной вёрсткой, RSS-сборщиком и панелью управления рекламой. Самостоятельный git-репозиторий; файлы проекта игры в родительском каталоге не используются.

## Быстрый локальный запуск

Нужен Go 1.25 или новее. Node.js, npm и сборщик frontend не нужны.

```bash
./scripts/dev.sh
```

Сайт: http://127.0.0.1:8080. Админка: http://127.0.0.1:8080/admin/.
Процессы работают до Ctrl+C. Скрипт собирает три программы и запускает их на loopback.

Чтобы создать администратора, в другом терминале:

```bash
./scripts/create-admin.sh
```

Email и пароль вводятся интерактивно; общего пароля по умолчанию нет. Пароль не менее 12 символов. Скрипт не сохраняет пароль в файлы.

При другом пути к Go:

```bash
GO_BIN=/absolute/path/to/go ./scripts/dev.sh
```

Порты можно изменить: `PORT=8787 ADMIN_PORT=8788 INGESTER_PORT=8789 ./scripts/dev.sh`.

## Что работает

- Главная с оригинальной графикой, рубрики, поиск, страницы новостей и пагинация.
- Сервер отдаёт полноценный HTML; новости, ссылки и реклама одинаковы с JavaScript и без него.
- Сохранение материалов в текущем браузере (localStorage).
- RSS/Atom-сборщик: ограниченные по размеру запросы, таймауты, повторные попытки, ETag/Last-Modified, стабильные ID, очистка HTML, дедупликация и SQLite WAL.
- Источники задаются в `data/sources.json`. По умолчанию подключены две общие RSS-ленты: https://www.sports.ru/rss/main.xml и https://www.championat.com/rss/news/. Количество лент не зашито в код.
- Сохраняются заголовок, краткий анонс, дата, рубрика и ссылка на оригинал. Полные чужие статьи не копируются. Отсутствие даты не подменяется «свежей» датой при каждом обновлении.
- Фоновое обновление каждые 60 секунд. При отказе всех источников предыдущая лента сохраняется. Статусы источников доступны на `/sources`.
- Опциональная загрузка изображений из RSS: `FETCH_IMAGES=true`; до 5 МБ/20 Мп, ресайз до 1280 px, SHA-256, очистка старых файлов, на которые нет ссылок в БД. По умолчанию используются собственные иллюстрации.
- Админка: вход, bcrypt, сессии, CSRF, ограничение попыток входа, загрузка PNG/JPEG/GIF, рекламодатель/ERID/ссылка, расписание, включение/выключение и удаление. Таблица аудит-лога хранится в SQLite.
- Реклама обновляется после сохранения; срок размещения проверяется также при выдаче страницы, даже если RSS-сервисы недоступны.
- `/api/v1/bundle`, `/api/v1/news`, `/api/v1/feed/stream`, `/feed.xml`, `/healthz`.

## Архитектура

```text
nginx :443
  ├─ trbn-backend :8080   → HTML, assets, API, RSS
  └─ trbn-admin :8081     → закрытая панель
trbn-ingester             → RSS → SQLite + atomic bundle.json
```

Исходники Go: `backend/`. Frontend: `frontend/`. HTML-шаблоны: `backend/templates/`. Общая база: `data/ingester.db`. Парсер и админка используют один формат данных в `backend/internal/model`.

Архитектура из гайда сохранена в части трёх процессов, Go, SQLite и bundle. Вместо React/Babel в браузере используется серверная вёрстка с небольшим обычным JavaScript: frontend по-прежнему не требует сборки, а HTML сразу доступен посетителю. Загрузка HTML5/ZIP-баннеров и интеграция непроверенного табло не входят в эту версию. Пустых матчей и вымышленных результатов нет.

## Проверка

```bash
cd backend
go test ./...
go vet ./...
go test -race ./...
```

Тесты охватывают RSS, дубли, условные запросы, сохранение последней ленты, категории, обработку HTML, изображения, SSR-фильтры/поиск/404, XSS, загрузку файлов, авторизацию, сессии, CSRF, рекламу и расписания.

## Сборка для передачи

```bash
./scripts/package.sh
```

Архив `dist/tribuna-linux-amd64.tar.gz` содержит готовые Linux-бинарники, исходники, статические файлы, демо-выпуск, конфигурацию RSS и инструкции. Не содержит пользователей, паролей, локальной БД и текущих загруженных новостей. Для ARM64: `GOARCH=arm64 ./scripts/package.sh`.

`package.sh` пересобирает `bin/` под Linux; после упаковки для локального запуска снова используйте `dev.sh`.

Инструкция для сервера: [deploy/README.md](deploy/README.md).

## Настройки владельца

В `.env` или `/etc/tribuna.env` задаются порты, каталоги и `CONTACT_EMAIL` — фактический контакт для рекламодателей. Пустое значение не заменяется придуманным адресом. Укажите реальный домен в nginx-конфигурации при развёртывании.

Условия использования RSS и изображений проверяет владелец перед публикацией. Источники всегда указаны на карточках и страницах. Реклама отображает переданные рекламодателя и ERID; сам идентификатор система не выдаёт и не проверяет в реестрах.

Если лента ещё пуста, показывается явно обозначенный демо-выпуск из `data/bundle.fixture.json`; он автоматически уступает место успешно загруженным новостям.

Для среды с синтетическим DNS 240/4 предусмотрен только локальный параметр `TRIBUNA_SYNTHETIC_DNS=true`. Исключение касается исключительно DNS-ответов для имён из настроенных RSS-источников; прямые локальные/служебные адреса остаются запрещены. На обычном VPS этот параметр не устанавливать.

Оригинальная иллюстрация стадиона: `frontend/assets/stadium-editorial.png`. Инструмент и исходный промпт: [ASSET-NOTES.md](frontend/assets/ASSET-NOTES.md).
