# Трибуна.ру

Отдельный спортивный новостной агрегатор с frontend, backend, ingester и admin-сервисом.

## Статус

Проект создан отдельно от исходного проекта игры. Реализация начинается с безопасного MVP:

- собственный дизайн в журнальной сетке;
- лента новостей через разрешённые RSS/API-источники и fixture-данные;
- SQLite-хранилище;
- прозрачные рекламные плейсменты;
- подготовка к запуску на Ubuntu VPS через nginx и systemd.

## Структура

- `backend/cmd/server` — сайт и API
- `backend/cmd/ingester` — сбор и нормализация новостей
- `backend/cmd/admin` — админка рекламных мест
- `frontend` — интерфейс портала
- `data` — локальные данные и fixture-файлы
- `deploy` — nginx/systemd-конфигурация
