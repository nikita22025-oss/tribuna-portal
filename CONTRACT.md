# Implementation contract

Repo root: tribuna-portal; Go module is backend/ (module tribuna-portal, Go 1.25).

Three processes from backend/cmd/server, cmd/ingester, cmd/admin. Runtime paths are absolute via DATA_DIR / FRONTEND_DIR / ADMIN_DB_PATH. Common defaults ../data, ../frontend when working directory backend.

JSON Article: id, title, summary, url (original source URL, blank for original editorial), source_id, source_name, tag (football/hockey/tennis/basketball/motorsport/other), image_path, published_at (RFC3339), is_demo (bool). No scraped full article body; internal article pages show RSS excerpt + original source link.

Bundle: issue {number,date,title}, nav [{id,label}], hero (Article|null), feed [Article], stories [Article], scoreboard [] (empty unless configured data), opinions [], ads [Ad], updated_at RFC3339, is_demo bool, sources [SourceStatus]. Article IDs hash URL. User-facing /news/{id}; category /?category=football; search /?q=term; page /?page=2. Public /api/v1/bundle, /api/v1/news?category=&q=&page=&limit=, /api/v1/feed/stream SSE; /healthz; /about /sources /advertise /privacy /bookmarks. Both server HTML and enhanced interface show same content including ads.

Go common model types in internal/model/model.go. Store API: data.Open(path) (*Store,error), Store.DB *sql.DB, Close(), UpsertItems(ctx, []model.Article) error, ListItems(ctx,limit int) ([]model.Article,error), ActiveAds(ctx) ([]model.Ad,error), BuildBundle(ctx) (model.Bundle,error), WriteBundle(ctx,dir string) error. Database schema centralized in data package, CREATE IF NOT EXISTS; admin may create own admin tables. Ads table ad_creatives: id TEXT primary key, placement TEXT, title TEXT, advertiser TEXT, erid TEXT, click_url TEXT, file TEXT, width INTEGER,height INTEGER,is_active INTEGER, starts_at TEXT,ends_at TEXT,created_at TEXT. Active ads need date-window handling. Images local /uploads/news or /uploads/ads. DB WAL + busy timeout.

Admin owns internal/admin + cmd/admin; config env DATA_DIR ADMIN_DB_PATH ADMIN_UPLOADS_DIR ADMIN_PORT ADMIN_SECURE_COOKIES (false local only). CLI `go run ./cmd/admin create-user --email ...` reads password from TRIBUNA_ADMIN_PASSWORD, never default password. Admin login /admin/login, dashboard /admin/; session HttpOnly SameSite Strict, CSRF, bcrypt, login rate limits, audit. uploads raster png/jpeg/gif ONLY max5MB decoded dims max5000; no arbitrary HTML/ZIP. labels, dates, URL and dimensions editable. Ad JSON: id,placement,title,advertiser,erid,click_url,file,width,height. Home slot names top,inline,sidebar. Empty slots show house message promoting own /advertise page.

Ingester owns internal/data + internal/ingester + cmd/ingester and data/sources.json; get common models from root. RSS sources configured in data/sources.json [{id,name,url,tag,enabled}]; conditional requests, timeout, max body and backoff, dedup stable URL, plain text excerpts, genuine dates, no fake match scores. Last good bundle survives failure. Only excerpt+source links, optional RSS-provided images if FETCH_IMAGES=true; default false. Network security common internal/netguard provided by root: Client(timeout time.Duration) *http.Client rejects private/local addresses + redirect targets. Tests can inject clients. Fixture demo handled public server if no feed DB. Ingester --once returns nonzero only if all enabled feeds fail; loop periodic default60s. local testing uses file fixtures via tests not public SSRF exceptions.

Frontend owns frontend/ and data/bundle.fixture.json (good authored demo with is_demo=true), backend/templates/index.html. Template must be Go html/template compatible; root public server will render it with Page {Bundle,Items,Article,Category,Query,Page,HasNext,Title,Mode,Initial template.JS,Body template.HTML}. Simplest index HTML has {{.Body}} in #root and <script id=initial-data type=application/json>{{.Initial}}</script>, head title {{.Title}}, root-rendered SSR body shares CSS with frontend. Coordinate SSR markup with root. JS can enrich existing SSR progressively OR React18/Babel; robust no-JS required same content. No third-party trackers. Own look inspired by chtv editorial grid, huge typography and strong red/orange header. No fake current news/statistics; authored demo label if no live data. Interactions category/search/bookmarks/article/load more work.
